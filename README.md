# Сборка

Веб-конструктор иллюстраций из исходных SVG. Откройте [index.html](index.html) в браузере. Сервер, установка зависимостей и интернет для запуска не нужны.

## Быстрая демонстрация

1. Нажмите «Вместе решаем задачи». Конструктор подберёт предметы по заголовку. «Кошелёк, монета, папка» показывает сборку по списку.
2. Смените формат, детализацию и палитру. Выберите предмет на холсте или в списке слоёв. Перетащите его и попробуйте поменять роль, угол или порядок слоёв.
3. Нажмите «Скачать SVG». Композиция сохраняется с отдельной векторной группой для каждого предмета.

На холсте выбранный объект можно двигать клавишами со стрелками. Shift увеличивает шаг.

## Как устроен проект

- `assets/catalog.js` хранит 10 предметов с названиями, синонимами, смысловыми тегами и четырьмя исходными вариантами. Там же находятся три SVG-фона и восемь цветовых ролей каждой схемы, взятые из таблиц Figma.
- `app.js` извлекает SVG нужной детализации и роли из каталога. Позиция, угол и порядок принадлежат экземпляру на холсте. За пропорции отвечают общая шкала раскладки и исходные размеры L. При переключении на S изображение вписывается в те же габариты с сохранением своего соотношения сторон.
- Подбор по заголовку использует словарь синонимов и смысловых тегов. По названиям используется точное совпадение с каталогом или синонимом. Раскладка детерминирована и использует один алгоритм для обоих сценариев. Если подходящих объектов нет, можно изменить запрос или выбрать их вручную.
- Цвета предметов заменяются по позициям образцов в исходных таблицах. Для своей палитры скачайте JSON-образец из редактора и загрузите его с двумя наборами из четырёх HEX-цветов. Своя палитра использует геометрию лавандового фона.
- При скачивании приложение сериализует SVG сцены с конкретными значениями цветов и трансформаций. Рамка выделения остаётся в интерфейсе.
